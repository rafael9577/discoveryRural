Como calcular o Bitmap ID

O Bitmap ID agrupa as características do animal em uma única soma matemática baseada em potências de 2.

Somente some os valores correspondentes ao animal:

CaracterísticaValor (Bit)
No alto (Árvores/Telhados)1
No chão (Grama/Asfalto)2
Na água ou margem4
É um Pássaro / Ave8
É uma Coruja16
É um Cágado / Tartaruga32
É um Lagarto64
É uma Cobra / Serpente128
É um Mamífero256

Exemplo: Se for um pássaro (8) que vive no chão (2), o Bitmap ID será 8 + 2 = 10.
